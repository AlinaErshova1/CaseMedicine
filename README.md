# AI-MRI: Система поддержки принятия врачебных решений

**AI-MRI** — это комплексная веб-платформа для анализа МРТ-снимков головного мозга с использованием компьютерного зрения (computer vision). Система помогает врачам выявлять новообразования, классифицировать их, сегментировать пораженные области и формировать итоговые протоколы диагностики.

Проект разработан в рамках кейс-чемпионата и представляет собой связку: **Frontend (Django)** + **Backend (FastAPI)** + **ML-модуль (PyTorch)**.

---

## Архитектура проекта

Проект разделен на три логических блока:
1. **Фронтенд и API шлюз (`myproject/`, `templates/`, `static/`)** — веб-интерфейс для врачей и администраторов на базе Django. Обеспечивает рендеринг страниц, авторизацию и взаимодействие с бэкендом.
2. **Бэкенд (`backend/`)** — REST API на FastAPI. Отвечает за бизнес-логику, безопасность, работу с базой данных PostgreSQL и маршрутизацию запросов к ML-моделям.
3. **ML-модуль (`ML/`, `pipeline.py`)** — пайплайн компьютерного зрения на PyTorch. Выполняет поиск опухоли, их выделение (при наличии), а также локализацию опухоли (местонахождение).

---

## Основные возможности

*   **Ролевая модель:** Разделение на администраторов (управление врачами, всеми пациентами, просмотр логов) и врачей (работа только со своими пациентами).
*   **Анализ МРТ в один клик:**
    *   Определение проекции снимка (аксиальная, корональная, сагиттальная).
    *   Классификация типа опухоли (глиома, менингиома, аденома гипофиза) с указанием уверенности модели.
    *   Автоматическая сегментация опухоли и расчет площади поражения в процентах.
    *   Определение анатомической локализации (полушарие и отдел мозга).
*   **Инструменты врача:**
    *   Возможность **ручного выделения** опухоли (кистью или полигонами) прямо поверх снимка, если ИИ ошибся или нужно более точное выделение.
    *   **Верификация данных:** врач проверяет результаты ИИ, при необходимости корректирует их, ставит галочки подтверждения и система генерирует официальное заключение.
*   **Экспорт:** Скачивание готового заключения в формате Word (.doc).
*   **Безопасность (152-ФЗ):** Шифрование персональных данных пациентов (ФИО, телефон, полис) с помощью Fernet.

---

## Стек технологий

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Django Templates.
*   **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.x, Pydantic, Uvicorn.
*   **База данных:** PostgreSQL 17.
*   **ML / CV:** PyTorch, Torchvision (EfficientNet, U-Net), OpenCV, NumPy, PIL.
*   **Безопасность:** JWT (python-jose), bcrypt (пароли), Fernet (шифрование данных).

---
## Безопасность

* **Персональные данные** пациентов не хранятся в открытом виде. Они шифруются алгоритмом Fernet перед сохранением в PostgreSQL.

* **Пароли** пользователей хэшируются и хранятся исключительно в виде bcrypt-хэшей.
 
* **Аудит всех действий** (вход, просмотр, анализ) ведется в файле logs.jsonl.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/AlinaErshova1/CaseMedicine.git
cd CaseMedicine
```

### 2. Настройка окружения
Создайте и активируйте виртуальное окружение:

Для Windows:

```
python -m venv .venv
.venv\Scripts\activate
```

Для Mac/Linux:

```
python -m venv .venv
source .venv/bin/activate
```

#### Установите зависимости:

```
pip install -r requirements.txt
```

(Убедитесь, что установлен bcrypt==4.0.1, иначе passlib может выдать ошибку).

### 3. Настройка .env
Создайте файл .env в корне проекта (рядом с manage.py) и заполните его:

```
DATABASE_URL=postgresql://postgres:ТВОЙ_ПАРОЛЬ@localhost:5432/medical_ai
FERNET_KEY=СГЕНЕРИРОВАННЫЙ_КЛЮЧ
SECRET_KEY=СЛУЧАЙНАЯ_СТРОКА
```

(Ключи можно сгенерировать через Python: from cryptography.fernet import Fernet; print(Fernet.generate_key().decode()))

### 4. Запуск базы данных и миграций
Создайте БД в PostgreSQL:

```
CREATE DATABASE medical_ai;
```

Примените миграции:

```
python manage.py migrate
python backend/seed_data.py
```

### 5. Запуск серверов (в двух терминалах)
Терминал 1 — FastAPI (Backend & ML):

```
uvicorn backend.api:app --reload --port 8000
```

Терминал 2 — Django (Frontend):

```
python manage.py runserver 8001
```

Интерфейс будет доступен по адресу: http://127.0.0.1:8001
